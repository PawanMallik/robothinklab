# RoboThinkLab - Future-Ready Robotics & AI Education

A modern, high-performance website for **RoboThinkLab**, built with the state-of-the-art AURA motion design system, featuring GSAP animations and Lenis ultra-smooth scrolling.

## Key Features & Content Included
- **Hero & Optical Wave Pattern**: High-impact entrance with interactive 3D mouse parallax and cosmic optical moiré background field.
- **Vision Statement**: Word-by-word scroll scrub reveal via GSAP ScrollTrigger highlighting the core belief of RoboThinkLab.
- **Three Core Pillars**: Educational Robotics, Research & Development, and Automation & AI Integration.
- **8 Turnkey School Services**:
  1. Dedicated Professional Trainer (On-campus full-time instructor)
  2. Complete Robotics Equipment & Practical Kits
  3. Turnkey School Lab Setup
  4. NEP 2020 Aligned Syllabus (Grade 1 to 12)
  5. Smart Board & Digital Integration
  6. Annual Exhibitions & City-Level Competitions
  7. Student Certification Accredited by RoboThinkLab
  8. AI, Python & Coding Mastery
- **Institutional Goals (Why Partner With Us)**: 6 key advantages covering curriculum, faculty development, customized solutions, affordability, infrastructure, and proven results.
- **About Us & Leadership**: Highlights founder **Suryansh Saxena** with company vision.
- **School Testimonials Slider**: Quotes from partner principals and academic directors with auto-slide and navigation dots.
- **Impact Metrics**: Animated counters for 50+ partner schools, 10,000+ students trained, 100+ labs deployed, and 15+ competitions.
- **School Partnership Inquiry Form**: Glassmorphic interactive form with input validation, designation selector, and immediate submission feedback.
- **Official Contact Details**: Campus address in Rudrapur, Uttarakhand, direct phone numbers (+91 84451 50518, +91 99276 73746), and verified social links.
- **Frequently Asked Questions (FAQ)**: Interactive accordion covering age groups, hardware provision, trainer assignments, and NEP 2020 compliance.

## Running Locally

```bash
# Start development server
npm run dev

# Build production bundle
npm run build

# Preview production bundle
npm run preview
```
Visit [http://localhost:5173](http://localhost:5173) in your browser.
